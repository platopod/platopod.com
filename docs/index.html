Start here

Plato Pod puts small robots on a shared arena that students drive from a browser, in plain English, or from their own Python code. Four demo rooms are open to anyone with the codes below: no account, no install. A teacher who wants rooms of their own asks for an invite.

The four demo rooms

Each room is open all the time and keeps its own setup. Join with its code at arena.platopod.com/join, or follow its link. The courses are examples, from UNSW Canberra, of where each room fits: any class at any level can use any room.

The first three run from a Python notebook, at home or in class. The fourth is played live: a teacher at the console starts the rounds.

Try it in five minutes

All you need is a laptop with a browser and Python 3.10 or later, or a Google account for Colab.

  1. Download the room's notebook (below) and open it in Jupyter, VS Code, or Google Colab (File, Upload notebook).
  2. Put your name in the second code cell (MY_NAME). The room's code is already there.
  3. Run the cells from the top. The first fetches the Plato Pod client from the server; the second joins the room, gives you a pod, and prints a link to watch it in 3D.
  4. Open that link beside the notebook and watch your pod do what your code says.

Your name keeps your pod: run the notebook again tomorrow with the same name and you get the same pod back. A pod nobody has used for 20 minutes leaves the room, which frees its place. The demonstration rooms take six people at once (the swarm room three, as each brings five pods), so everyone who gets in has a pod that answers; a room of your own takes 12.

Without a notebook, you can still look in: join from arena.platopod.com/join with the code and a name, and the page links to your pod on the table and in 3D.
