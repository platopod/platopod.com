History

Three versions, one idea.

From the start, Plato Pod has been about one camera over a table of small robots, with software filling in the rest of the world. What that world contains has grown with each version.

1

A camera that plays every sensor

KoreaTech, Korea

The first platform was built at the Korea University of Technology and Education to make programming classes less about memorising a language and more about making something move. One camera watched the whole table, and a computer-vision algorithm turned what it saw into the robots' sensors, so a line follower, a maze, a vacuum cleaner and a game of tag could all be set without extra hardware. The robots ran on the Robot Operating System and were reached over the network, so students could program them from anywhere.

Artem Lenskiy, Heo Junho, Kim Dongyun and Park Junsu, “Educational platform for learning programming via controlling mobile robots”, IEEE Xplore.

2

The second platform

KoreaTech, Korea

A second version followed at KoreaTech.

3

A world around the robots

UNSW Canberra, Australia

At UNSW Canberra the platform became what it is today: new pods on Bluetooth, a server built on ROS 2, and around the robots a simulated world of sensors, hazards, virtual units and an opposing force, shared with ATAK. It is built for the classroom and for rehearsal alike.
