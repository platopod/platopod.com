Teaching with real robots.

Students program real pods in a simulated world of sensors, obstacles, hazards and other robots. The exercises run from a first sensor loop to feedback control, in any language with a WebSocket client, or in plain English with no code.

Exercises, simplest first

1 · Coverage

Sweep for mines

The vacuum-cleaner problem: cover the arena and find mines hidden in it. Start with a random walk, then a zig-zag, then two pods sharing out the ground. The strategy is one function with its own tests.

2 · Pursuit

Tag

One pod evades and one pursues, each planning a path round the obstacles.

3 · Search

Find the gas source

Follow a simulated gas sensor to a hidden leak. Reference solutions at three levels: random walk, gradient ascent, and a search that respects rules of engagement.

4 · Sensing

Capture the flag

Two teams, their zones and a flag, laid out among obstacles. Each pod is given a set of simulated sensors, chosen from sonar, lidar, radar and others with adjustable noise, so a team plans around what its sensors can and cannot see.

5 · Teams

Get through unseen

One side places sensors and commands a patrol; the other gets its pods across the arena undetected, using cover. Real pods and virtual units play in the same game.

6 · Control

Follow a path

Draw a route in the browser and a pod drives it. The controller is pure pursuit with PID on heading, its gains exposed, so students tune each term and see the result on a real robot.

No code

The plain-English track

Students write a strategy in plain English, such as how to sweep a room or take a flag. It is translated into a fixed set of orders (go to, patrol, sweep, follow, keep away, wait, stop) and read back before anything moves, so a team sees what the machine understood. Used in October 2026 in a postgraduate surveillance course at UNSW Canberra.

Student code

Python, C, Java and JavaScript each have a small library with the same calls. Underneath is JSON over a WebSocket, so any other language with a WebSocket client can drive the arena too. Each example takes a pod no one else is driving, waiting if they are all in use, reads its simulated sonar and turns away from anything closer than 20 cm.

Python

from platopod import Arena

arena = Arena("ws://ARENA-ADDRESS:8080/api/control")
pod = arena.take_pod()                   # waits for a pod no one else is driving

arena.subscribe_sensors(pod, ["sonar"])

while True:
    sonar = arena.get_sensor(pod, "sonar")
    if sonar:
        ahead = sonar["ranges"][0]         # beam 0 points ahead
        if ahead < 0.20:                   # within 20 cm
            arena.cmd_vel(pod, 0.0, 1.2)   # turn on the spot
        else:
            arena.cmd_vel(pod, 0.10, 0.0)  # drive forward
    arena.sleep(0.1)

C

#include "platopod.h"

int main(void) {
    pp_arena *arena = pp_connect("ws://ARENA-ADDRESS:8080/api/control");
    int pod = pp_take_pod(arena);                    // waits for a pod no one else is driving

    pp_subscribe_sensors(arena, pod, "sonar");

    while (1) {
        double ahead;
        if (pp_sensor_num(arena, pod, "sonar", "ranges[0]", &ahead)) {  // beam 0 points ahead
            if (ahead < 0.20)                                             // within 20 cm
                pp_cmd_vel(arena, pod, 0.0, 1.2);                         // turn on the spot
            else
                pp_cmd_vel(arena, pod, 0.10, 0.0);                        // drive forward
        }
        pp_sleep(arena, 0.1);
    }
}

Java

import platopod.Arena;
import platopod.Json;

public class Avoid {
    public static void main(String[] args) {
        Arena arena = new Arena("ws://ARENA-ADDRESS:8080/api/control");
        int pod = arena.takePod();                     // waits for a pod no one else is driving

        arena.subscribeSensors(pod, "sonar");

        while (true) {
            Json sonar = arena.getSensor(pod, "sonar");
            if (sonar != null) {
                double ahead = sonar.get("ranges").at(0).asDouble();  // beam 0 points ahead
                if (ahead < 0.20) {                                   // within 20 cm
                    arena.cmdVel(pod, 0.0, 1.2);                      // turn on the spot
                } else {
                    arena.cmdVel(pod, 0.10, 0.0);                     // drive forward
                }
            }
            arena.sleep(0.1);
        }
    }
}

JavaScript

import { Arena } from "./platopod.mjs";

const arena = await Arena.connect("ws://ARENA-ADDRESS:8080/api/control");
const pod = await arena.takePod();          // waits for a pod no one else is driving

arena.subscribeSensors(pod, ["sonar"]);

while (true) {
  const sonar = arena.getSensor(pod, "sonar");
  if (sonar) {
    const ahead = sonar.ranges[0];          // beam 0 points ahead
    if (ahead < 0.20) {                     // within 20 cm
      arena.cmdVel(pod, 0.0, 1.2);          // turn on the spot
    } else {
      arena.cmdVel(pod, 0.10, 0.0);         // drive forward
    }
  }
  await arena.sleep(0.1);
}

A real pod has a narrow range of speeds, so the server fits each command to what that pod can do.
