Teaching with real robots.

Your students write a plan and watch a real robot carry it out. The same arena serves a school class with no code, a first programming course, and final-year work on control and planning.

A lesson at three levels

  • SchoolStudents write orders in plain English, such as how to sweep a room or take a flag. The orders are read back before anything moves, so the class sees what the machine understood. No code.
  • First courseTen lines of Python drive a pod: read its sonar, turn away from the wall, try again. Any language works.
  • AdvancedTune a controller and watch a real robot settle. Plan routes round obstacles. Make two pods share a job. Play a team game against sensors and cover.

How a class runs

  • A roomYou make a room and get a six-letter code, with an arena for each group. Your page links each group's console, projector picture and 3D view.
  • A pod eachA student types the code and their name and gets a pod of their own, with its colour. The same name gets the same pod back.
  • A refereeEvery exercise tells the students the task, enforces its rules, ends on time and marks the result. The same exercise gets harder by changing the rules: the keys, a drawn route, orders in plain English, a program.

Exercises

1 · Control

Draw a path

Draw a route on the screen and a pod drives it. Students tune the controller and watch a real robot overshoot, settle and track the line.

2 · Pursuit

Pursuit

One pod chases and one evades, each planning a path round the obstacles. Students write the strategy for either side.

3 · Class

Class pursuit

Every pair at once, or one side against the other, the whole class driving and the referee keeping score.

4 · Coverage

Route clearance

Find the mines hidden in the arena: a random walk first, then a pattern, then two pods sharing the ground. Students watch coverage and time improve with each strategy.

5 · Patrol

Patrol

A lap round the arena on time, reporting what changed since the last one.

6 · Teams

Get through unseen

One side places sensors and commands a patrol; the other slips its pods across using cover. Real pods and virtual units in one game.

7 · Search

Find the gas source

Follow a simulated gas sensor to a hidden leak, from a random walk to climbing the gradient.

8 · Sensing

Capture the flag

Two teams, their zones and a flag among obstacles. Each pod has its own set of simulated sensors, with their noise, so a team plans around what it can and cannot see.

No code

The plain-English track

Students write a strategy in plain English. It is turned into a fixed set of orders (go to, patrol, sweep, follow, keep away, wait, stop) and read back before anything moves, so a team sees what the machine understood. Used in October 2026 in a postgraduate surveillance course at UNSW Canberra.

Example code

This takes a free pod, reads its sonar and turns away from anything closer than 20 cm. The same calls exist in C, Java and JavaScript, and any language that can open a web connection can drive the arena: see how it works.

Python

from platopod import Arena

arena = Arena("wss://a.arena.platopod.com/api/control")
pod = arena.take_pod()                   # waits for a pod no one else is driving

arena.subscribe_sensors(pod, ["sonar"])

while True:
    sonar = arena.get_sensor(pod, "sonar")
    if sonar:
        ahead = sonar["ranges"][0]         # beam 0 points ahead
        if ahead < 0.20:                   # within 20 cm
            arena.cmd_vel(pod, 0.0, 1.2)   # turn on the spot
        else:
            arena.cmd_vel(pod, 0.10, 0.0)  # drive forward
    arena.sleep(0.1)
